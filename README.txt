ZILAL TRAVEL — автономная HTML-версия

Откройте ZILAL-TRAVEL.html двойным щелчком в современном браузере. Интернет, Node.js и Next.js не требуются. JavaScript должен быть включён. Все страницы, каталог, фильтры, галереи и конструктор находятся в одном файле.

Для переходов используйте меню сайта. Данные конструктора сохраняются между шагами в текущем окне, но сбрасываются при перезагрузке. Все маршруты — примеры. Формы работают в демонстрационном режиме, ничего не отправляют и не создают бронирование. Изображения — оригинальные иллюстрации проекта.

React и React DOM распространяются по лицензии MIT. Уведомления включены в HTML и в THIRD_PARTY_LICENSES.txt.
