# ZILAL TRAVEL

Первая версия главной страницы: Next.js App Router, TypeScript, Tailwind CSS 4. Весь интерфейс на русском, контент разделён на компоненты. `lib/content.ts` содержит словарь `ru`, который можно расширить английской локалью и затем подключить языковую маршрутизацию.

## Запуск

Требуется Node.js 22 или новее (проверено на Node.js 24).

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000 в локальном браузере.

```sh
npm run typecheck
npm run build
npm start
```

В облачной среде с ограниченной записью npm-кэша: `npm ci --cache /tmp/zilal-npm`.

## Основные файлы

- `app/page.tsx` — композиция главной страницы: первый экран, преимущества, концепции туров, направления, будущий конструктор, культура и контакты.
- `app/globals.css` — Tailwind, палитра, адаптивная сетка, типографика, анимации и reduced-motion.
- `components/Header.tsx` — навигация и мобильное меню.
- `components/InquiryForm.tsx` — демонстрационная форма с HTML-валидацией и доступным статусом результата. Данные не отправляются и не сохраняются.
- `components/AnchorDetails.tsx` — раскрытие описаний направлений и конструктора при переходе по якорям.
- `components/Photo.tsx` — оригинальные SVG-заглушки вместо непроверенных фотографий.
- `lib/content.ts` — русские тексты, направления и подписи иллюстраций.
- `app/layout.tsx` — SEO-метаданные, язык документа, ссылка пропуска навигации. Индексация отключена для демонстрации; перед публикацией заменить metadata и добавить реальный canonical URL.
- `app/privacy/page.tsx`, `app/sources/page.tsx` — конфиденциальность и состояние источников изображений.
- `PHOTO_SOURCES.md` — требования к лицензиям и будущей атрибуции.

## Ограничения демоверсии

Реальных контактов, туров, цен, отзывов и наград нет. Кнопки ведут к разделам и раскрывающимся временным экранам. Конструктор маршрута пока заменён пояснением и формой. Для реального приёма заявок нужны серверная обработка, защита от спама, контакты оператора и актуальная политика обработки данных.

Фотографии Кыргызстана ещё не подключены: исходящие запросы к фотосервисам отклонены сетевой политикой (403). Все видимые пейзажи — оригинальные векторные иллюстрации, а не фотографии конкретных мест. Это незавершённое требование дизайна. После разрешения доступа подобрать и проверить лицензированные фото, скачать локально в `public/images`, обновить компонент и атрибуцию. Сайт не зависит от внешних изображений или шрифтов.
