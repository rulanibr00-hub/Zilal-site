# ZILAL TRAVEL — контрольная копия после этапа №11

- `ZILAL-project.zip` — исходники основного Next.js-проекта, миграции, тесты и документация. Инструкция запуска — README_CHECKPOINT.md внутри архива.
- `ZILAL-screenshots.zip` — 56 скриншотов публичного сайта и админки, desktop/mobile.
- `SHA256SUMS.txt` — контрольные суммы SHA-256.

Откройте нужный ZIP на GitHub и нажмите Download raw file (значок скачивания). Для приватного репозитория требуется вход в GitHub с правом доступа.

Исключены node_modules, .next, .git, реальные .env, ключи, токены, пароли, БД и реальные данные клиентов. .env.example безопасный; приём заявок и Telegram-сеть выключены. Это передача резервной копии, не публикация сайта. Основная ветка не изменяется.
