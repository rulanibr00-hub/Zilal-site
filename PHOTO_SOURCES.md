# Фотографии

Проверенные фотографии пока отсутствуют. Доступ к Unsplash и Wikimedia Commons из среды отклоняется сетевым прокси (HTTP 403). Непроверенные изображения не используются и не выдаются за лицензированные фотографии Кыргызстана.

Текущие фоны — оригинальные векторные иллюстрации, созданные для проекта в components/Photo.tsx; это не фотографии конкретных мест. Перед публичным запуском заменить их реальными лицензированными снимками Кыргызстана.

Для каждого будущего изображения сохранить: локальный путь, название места, имя автора, URL оригинальной страницы, название и URL лицензии, дату загрузки, изменения изображения. Проверять условия отдельно для каждого файла; наличие на Wikimedia само по себе не заменяет проверки лицензии.
